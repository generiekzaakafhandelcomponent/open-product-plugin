# Release notes

Overzicht van wijzigingen per versie van de Open Product-plugin.

## 2.0.0
Geschikt gemaakt voor Valtimo 13.24.0 en ondergebracht in een eigen repository, met voorbeeldapplicatie en aparte documentatie.

## 1.0.0
Eerste publieke release: producten beheren via de Open Product API, geschikt voor Valtimo 13.
